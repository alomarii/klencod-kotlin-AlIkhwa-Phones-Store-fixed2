# تطبيق الاخوة للهواتف (أندرويد)

## الفكرة
- واجهة للعملاء: الأقسام + البحث + شبكة منتجات + صفحة تفاصيل بصور متعددة + سلة.
- زر "إرسال الطلب عبر واتساب" يرسل قائمة المنتجات والإجمالي إلى الرقم 00967771921031 (يمكن تغييره من الإعدادات).
- لوحة الإدارة: إضافة/تعديل/حذف المنتجات والصور والتفاصيل والأسعار والتوفر، إدارة الأقسام، تغيير اسم المتجر ورقم الواتساب والعملة وكلمة السر.
- **الدخول للوحة الإدارة:** اضغط ضغطة مطولة على اسم المتجر في أعلى الشاشة الرئيسية ← اسم المستخدم `alomari` وكلمة السر `alomari`.

## خطوات التشغيل (مرة واحدة)
1. أنشئ مشروعاً في https://console.firebase.google.com
2. أضف تطبيق Android باسم الحزمة: `com.alikhwa.phones` ثم حمّل ملف `google-services.json` وضعه داخل مجلد `app/`.
3. من Build > Authentication فعّل طريقة **Email/Password**.
4. من Build > Firestore Database أنشئ قاعدة بيانات، ثم من تبويب Rules الصق:

```
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /{document=**} {
      allow read: if true;
      allow write: if request.auth != null
                   && request.auth.token.email == 'alomari@alikhwa.store';
    }
  }
}
```
5. افتح المجلد في Android Studio ← Sync ← Run (أو Build > Build APK).
6. افتح التطبيق، ادخل لوحة الإدارة (أول دخول ينشئ الحساب تلقائياً)، أضف الأقسام ثم المنتجات.

## ملاحظات
- الصور تُضغط تلقائياً وتُخزن داخل Firestore (حتى 4 صور لكل منتج) فلا تحتاج Firebase Storage المدفوع.
- يُنصح بتغيير كلمة السر من الإعدادات بعد أول دخول.
- التطبيق يعمل على أندرويد 7.0 فأعلى.

## إصلاحات النسخة المصححة
- ملف `google-services.json` **إلزامي** وغير موجود في الحزمة: حمّله من Firebase وضعه في `app/` وإلا سيفشل البناء.
- الإصدار release أصبح موقّعاً تلقائياً (بمفتاح debug) ليكون قابلاً للتثبيت. للنشر على Google Play أنشئ مفتاح توقيع خاص.
- الأفضل للتجربة: Build > Build APK(s) من Android Studio (JDK 17).
- غيّر كلمة السر الافتراضية `alomari` فور أول دخول.
